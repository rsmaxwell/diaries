# Archived 0031 tooling

This directory was created by 0032-FEAT Step 3 after 0031 had already closed. It preserves byte-identical final source copies of completed-feature migration, evidence-capture and historical validation tooling that was still present in live Diaries/Playbooks script or test directories.

The archived paths were **not** the paths used while 0031 was implemented. Existing 0031 runtime evidence and historical commands remain historical records of the paths valid at that time.

Contents are split into:

- `windows/` — feature-step development/evidence helpers from the Diaries repository;
- `production/` — retired 0031 production helpers from the Playbooks sync tree;
- `validation/diaries/` — historical Diaries validators;
- `validation/playbooks/` — historical Playbooks validators.
