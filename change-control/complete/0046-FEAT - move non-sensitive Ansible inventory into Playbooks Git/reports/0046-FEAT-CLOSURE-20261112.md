## 2. Operational procedure

The canonical checkout on `mango` is `/home/richard/ansible-controller`.

From an interactive Bash shell on `mango`:

```bash
source "$HOME/ansible-controller/enter.sh"
```

This enters `$HOME/ansible-controller/playbooks`, sets `ANSIBLE_INVENTORY` to `$HOME/ansible-controller/inventory/hosts`, and uses `ANSIBLE_CONFIG=/etc/ansible/ansible.cfg`. It does not edit global Ansible configuration or modify managed hosts. For example:

```bash
ansible pluto -m ansible.builtin.ping --vault-password-file "$HOME/.vault_pass.txt"
```

The controller README was updated to document the completed cutover, removal of the previous checkout and the new clone procedure, and committed to the private parent repository in revision `f6ba7fec7752f4bbfa1535958500bde9dea3ea84`.
