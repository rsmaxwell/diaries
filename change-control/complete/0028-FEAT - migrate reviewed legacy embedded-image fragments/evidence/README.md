# 0028 acceptance evidence

Create `Step 1/`, `Step 2/`, `Step 3/` and `Step 4/` only when real work yields
evidence; preserve raw logs, command exit status, dates, tested code revisions,
manifest/file hashes, database backup and Files-root snapshot receipts,
rehearsal outputs, deployment identities and formal acceptance decision.

This planning package does not claim any implementation gate has passed.
Private diary text, production database extracts, secrets and media should
remain in appropriately access-controlled evidence/backups. Redact or hash
private data before sharing reports or committing evidence intended for
broader distribution. Do not store evidence permanently under the Playbooks
repository or a general `/home/richard` staging directory.
